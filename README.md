# GNEZDO Property Audit

Плагин для предварительной комплексной проверки земельного участка и здания перед покупкой в России.

Проверяет документы, права и обременения, ПЗЗ и соответствие ВРИ градостроительным регламентам, судебные риски, продавца и пригодность объекта под цель покупателя. Для Крыма и Севастополя предусмотрены отдельные источники и оговорки.

## Установка в Codex

В терминале выполните:

```bash
codex plugin marketplace add Leelyya/gnezdo-property-audit
```

После этого перезапустите приложение ChatGPT/Codex, откройте каталог плагинов, выберите источник `GNEZDO Plugins` и установите `GNEZDO · Проверка недвижимости`.

## Как запустить проверку

В новом чате прикрепите документы по объекту и напишите:

```text
Используй $gnezdo-property-audit для глубокой проверки перед покупкой.
```

Плагин попросит подтвердить только состав проверки: земельный участок, объект или земельный участок с объектом. После подтверждения он автоматически выполнит все применимые блоки комплексного аудита, включая документы, права, ограничения, ПЗЗ и ВРИ, суды, продавца и пригодность под цель. Доступные сведения плагин сначала извлекает из приложенных документов самостоятельно.

## Важно

Плагин готовит предварительный доказательный аудит по предоставленным документам и доступным источникам. Он не заменяет официальные выписки, заключение кадастрового инженера, адвоката, нотариуса или профильного специалиста.
