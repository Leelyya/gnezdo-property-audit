## Нормативная карта

Это индекс для подбора актуального правового основания. Не все нормы применимы к каждому объекту. Ссылку на норму добавляй в вывод только после чтения соответствующего положения и проверки даты/исключений.

- 218-ФЗ о регистрации недвижимости: [актуализируемый справочный текст](https://www.consultant.ru/document/cons_doc_LAW_182661/) открыт; для конкретной сделки нужны применимая статья и редакция. Отдельно исследовать приостановление, границы, ограничения доступа к данным и ранее возникшие права.
- Градостроительный кодекс: [справочный текст](https://www.consultant.ru/document/cons_doc_LAW_51040/) открыт, на странице обозначена редакция от 04.08.2026 с изменениями с 01.09.2026. Это не индивидуальная оценка разрешённости строительства; открывать конкретные статьи и местные регламенты.
- Гражданский/Земельный/Водный/Лесной/Семейный кодексы; 127-ФЗ о банкротстве; 102-ФЗ об ипотеке; 73-ФЗ об объектах наследия; 7-ФЗ об охране среды; 101-ФЗ об обороте сельхозземель; 214-ФЗ при применимости; технические и пожарные требования: маршрут последующей проверки, актуальные тексты по делу ещё не исследованы.
- Для границ найдено [разъяснение Управления Росреестра по Татарстану](https://rosreestr.tatarstan.ru/index.htm/news/2382224.htm) об изменениях с 01.03.2025. Текст был виден в поисковой выдаче, повторное открытие завершилось таймаутом. Не использовать как единственное основание индивидуального запрета; читать применимые положения 218-ФЗ, исключения и документы объекта.
- Для персональных данных ЕГРН найдено [разъяснение государственного центра кадастровой оценки](https://cgko.sakha.gov.ru/o-novykh-pravilakh-predostavleniya-pers/); повторное открытие завершилось таймаутом. Порядок выдачи определять по действующим нормам и статусу заявителя.
- Для продукта открыт [текст 152-ФЗ на сайте Минтруда](https://mintrud.gov.ru/docs/laws/130), на странице перечислены изменения по 24.06.2025. Перед запуском проверить более поздние изменения и применимость требований, включая основания обработки, локализацию, передачу и обязанности оператора. Согласие само по себе не заменяет выполнение остальных требований.

КонсультантПлюс здесь - справочный правовой ресурс, не официальный издатель нормативных актов. При расхождении или существенном выводе сверять с официальным опубликованием.

## Судебный протокол

Сначала ИНН/ОГРН юридического лица либо законно предоставленные идентификаторы физлица, затем прежние наименования/адреса/релевантные владельцы. По объекту - кадастровые и прежние номера, адресные варианты, реквизиты оспариваемых актов. Не отправлять паспорт целиком в поиск.

По каждому найденному делу: номер, суд, стороны и их роли, подтверждение идентичности, предмет, связь с объектом, текущая стадия, акты и даты, обеспечительные меры, вступление в силу/обжалование, исполнение, последствия для покупки. Не выдавать прогноз исхода за установленный факт.

Негативный результат формулировать ограниченно: «На дату X в источнике Y по запросам Z за период P относимых записей не обнаружено; ограничения проверки: ...». Для неподтверждённого совпадения личности использовать «возможное совпадение», пока идентичность не установлена.
